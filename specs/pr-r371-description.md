## 问题

替代已关闭、未合并的 #23，保留它的完整 R366 改动，整合本地 R367 预设组件与前三项会话修复。Mod 获取更多后返回会重进会话；强渲染消息长按误触文字选择；大卡的脚本启用竞态及字体 CSS 阻塞拖慢显示。

## 影响

Android 会话往返和大卡切换体验不稳定，用户难以在强渲染正文中使用原有回溯操作。仅提交原生文件会遗漏实际网页运行时，因此本 PR 同时交付完整有序补丁与构建输入。

## 修复

- 原有 R366 全部保留，随后按顺序应用 R367、R368 增量补丁。
- Mod 导航交给原生常驻页宿主，返回保留同一 WebView、文档和会话。
- 精确绑定强渲染/嵌套 iframe、消息及账号 epoch，转发长按到原菜单；保留控件、滚动及显式文字选择。
- 选中卡脚本启用在切卡前准备、切卡后确认，移除固定 500ms 等待和旧卡复选框竞态。两处嵌入消息 iframe 改为 eager，脚本 iframe 不变。
- Google 字体样式移出消息显示的阻塞链，原字体仍下载、原回调保留；脚本、普通样式、变量初始化不删减。
- HTTP 缓存只做一次旧策略迁移，后续升级不反复清掉外部卡资源；登录/本机存档不清理。
- 补预设组件 manifest；按 Git 的二进制属性导出 Helper 包，避免改坏字符串换行。
- 371 / 1.18.14。只提交源码，不合并、不发布正式 APK、不部署后端；不加新的 ChatArchive 恢复内容。
