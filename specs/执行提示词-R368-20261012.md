# 当前执行提示词

这次不是换配色或隐藏等待画面，而是修复软件的会话生命周期和消息操作，
并继续恢复用户指定的原版代码。用户已明确确认风月与 ChatArchive 的源码
修改、移植授权；不再重复索要证明。授权不等于已有完整原版工程。

## 范围与不变条件

只改惑梦 Android 软件及其内置代码，不改网站、服务器或正式版。本轮不
提交、不发布。保留已经完成的预设悬浮球移植，以及本机优先存档、账号
隔离、云端同步、模型/预设配置、正则、Mod、长记忆和卡内交互。不能用
关闭扩展、截断角色卡或消息、隐藏真实错误的方式制造流畅假象。

## 1. 获取更多 Mod 后返回

复现已有会话 → 右上角 Mod → 获取更多 Mod → 返回。区分 iframe 导航、
宿主网页导航、WebView 重建和重新初始化。返回必须恢复同一个会话运行时，
消息、草稿、滚动位置和设置保留，不重新出现“正在进入梦境”。覆盖页面
返回、Android 返回、后台返回以及连续重复操作。进程真实被系统回收时
从本机数据恢复，不能等完整云同步才显示已有消息。错误必须可见且可重试。

## 2. 风月加载源码与大卡

使用已经恢复的风月真实代码，追踪保留聊天 WebView、开场 HTML、消息读取、
桥接 ready 和界面呈现的调用链，不能只搬一个加载动画。对具备完整实现
的部分保留来源和改动说明；明确需要原生/React/数据库/接口适配的范围。
若不能直接接入，就记录真实技术缺口，不能把独立重写称为原码移植。

用用户提供的《道渊》v5.2 大卡检查首次进入、重复进入、左侧历史 A→B→A。
分开测量本地读取、角色装载、世界书/正则、脚本、iframe 最终画面和可操作
状态。不能先出现原始代码或普通气泡，再延迟变为最终渲染。保留完整源
数据及功能，以点击到最终可操作画面为验收，不以内部 ready 标志冒充。

## 3. 无气泡强渲染消息操作

长按强渲染开场白和后续消息正文，应打开现有消息菜单并能回溯/撤回，不
误触浏览器文本选择。普通 DOM、卡内 iframe、嵌套 iframe 都要检查。每次
操作绑定确切消息、会话、账号及文档，旧 iframe 或迟到事件不能操作新
会话。短按按钮/链接、输入、文字编辑、滚动照常；不要全局禁用文字选择。
验证长按、滑动/双指取消、菜单关闭、回溯确认/取消与切卡后的事件隔离。

## 4. ChatArchive 原版实现

继续从提供的 1.2.6 Windows/Android 包和既有反编译证据恢复真实普通玩法。
区分方法体、诊断桩、旧版空实现、类型身份和素材，不重复运行已失败的
巨大恢复流程来代替进展。沿新证据推进依赖和载入链，不绕过访问/许可控制，
不接触用户账号和旧存档，不联系原作者。现有重建版不得冒充原版。

取得可用实现后去除导演入口和调用链，保留横屏普通玩法、角色交互、场景
及持久化，接入既有模型和本机优先存档。素材按需下载，不全部塞入 APK；
素材卸载/重下不能破坏独立存档。尚缺主玩法时明确记录缺失，不能交付假的
“全部恢复”结果。

## 验证与交付

使用隔离合成账号/存档，不对用户记录做删除或改写测试。检查最终 APK 的
真实 Activity、实际导航客户端与桥，不用替代 WebView 冒充。覆盖普通卡、
强渲染大卡、离线/联网、后台/返回、切卡、消息菜单、保存、预设球及长记忆。
同时跑逻辑测试、原生单测、lint/build、资源/源码校验及补丁链重建。

每项分别报告通过、失败、未测试和阻塞。浏览器结果不能当手机结果，
静态源码不能当实测；未达到的冷启动或大卡速度不能写成“秒开”。交付
本地验收 APK 必须说明完成范围，不声称四项全完成，不提交正式版。
