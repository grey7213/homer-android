2. 已完成：独立路由与共用组件：首页、搜索、详情、发布/编辑、个人动态、收藏中的社区标签、作者主页、社区消息。重做字号、密度、图标、导航、评论输入和反馈。
3. 已完成可执行验证：浏览器 390×844、360×800、1440×900 全链路、权限与返回位置、60 项社区 API 回归、Android 返回/媒体选择器/草稿及本机交互通过。模拟器无法显示可见软键盘，键盘遮挡留作真机复核，不能标为已通过；小黑盒登录后对照仍待用户完成登录。
4. 已完成：构建、安装并复验 R7 debug，APK 保存到 `D:\网站\惑梦-社区独立页面R7-debug-20260917.apk`；新页面全部入包。最新累计补丁 `web-patches/20260917-0738-android-community-r7-independent-screens.patch` 已通过反向检查，旧累计补丁归档保留。证据与边界见 `COMMUNITY_R7_ACCEPTANCE.md`。

验收：主流程不使用详情/写帖大对话框；次级页面不露底页、无底部主导航；独立 URL 可重载；正文 15–16px、按钮触点至少 44px，主要/次要文字对比清晰；无评论不显示分页；附件工具不独占大行；返回恢复列表；本机标识常驻但不挤占首屏；没有线上写请求。

风险：多页面草稿和媒体 Blob 地址需重载恢复；后退不能重复进入编辑器；原收藏角色与社区帖子不能互相覆盖；Android 内置资源索引必须包括新页面；多层 CSS 不能再次造成半屏弹窗。

## 行为规格与证据区分

- 已观察（小黑盒旧采集）：关注/推荐为一级切换，搜索/消息为独立入口；紧凑话题横栏；信息流以作者→内容→媒体→互动排列，浅灰分隔，无大块说明文案。
- 已观察（本项目）：R6 把搜索直接插入列表，详情与编辑使用 dialog；部分全局控件规则导致图二右边露底、按钮空白较大。
- 用户明确要求：搜索、写帖、详情、个人收藏、动态等成为单独界面。
- 本次自主设计而非声称小黑盒精确测量：56px 页面头、16px 内容边距、44px 触点；标题18/22px、正文16px、辅助12/13px；白色内容面、浅灰背景、深色正文、品牌玫红选中态。
- 搜索：空输入显示近期搜索和话题；帖子/用户/话题分标签；提交后列表、空态、错误重试。
- 详情：独立返回栏；作者及关注、标题正文媒体、点赞收藏分享、评论排序、评论列表；底部紧凑输入，附件按需展开，分页仅多页时出现。
- 编辑：独立页；退出自动保存；标题/正文/媒体/版块/标签；发布禁用与错误保留内容；成功替换编辑路由到详情。
- 收藏：复用 `/app/favorites.html`，新增 `?tab=community` 展示帖子；不另建收藏数据或第二个“我的”。个人动态从现有“我的”与作品页入口进入。
- 本机模式：所有上述页面沿用同一隔离数据；短标识“本机验收 · 不上传”，点击查看管理/退出/重置说明。
