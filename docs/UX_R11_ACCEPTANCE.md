## 本轮修改

### 用户功能

- 纯净区搜索保留 zone 参数；根据用户明确答复，维持排除猎奇等的现有定义，不新增成人内容限制。
- 历史会话支持搜索和更新时间；清理列表中的 HTML、代码块、思维标签等摘要，窄屏更多按钮不再另占整行。只处理列表摘要，不改原始消息。
- 手机角色编辑页重排保存、导入、预览和公开状态操作，避免挤出屏幕。
- 创作资源页移除失效的预览函数调用，普通已登录创作者可进入；增加预设/世界书文件读取及相册封面上传入口，错误 JSON 不覆盖已导入内容，导入不自动发布。
- “我的”继续复用原界面，创作入口名称明确、头像可从相册选择，管理员有直接后台入口，不再经过桌面完整账户页。
- 对话返回键优先关面板，离开对话清理临时抽屉；重新打开存档保留输入区。
- 预设开关支持完整列表和查找；长记忆直达实际记忆书，等待扩展真实就绪。提供最近 20 条/全部已加载范围，选中消息摘要折叠，高级操作与取消范围文案更明确。生成逻辑未替换。
- 运营配置按分类显示；全局预设条目折叠时不创建隐藏的大量编辑控件，展开才挂载，未展开条目数据不丢失。
- 购买说明不再把回复次数估算表达为保证值，计价/支付逻辑不变。

### 用户与管理员边界

- 管理入口依赖最新服务端身份，不能只凭本地缓存中的管理员标记显示；后台入口还校验已验证用户 ID 和管理员身份。
- 领域服务测试对 15 类管理接口验证普通身份不能通过伪造请求体管理员字段越权。不能以隐藏按钮替代后端鉴权。
- 本机社区验收仍限 Debug + 最新验证的管理员；退出模式清除标识，常驻页面重新显示时重新校验模式。旧本机编辑页不会变成线上发帖入口，本机草稿媒体按原模式保存。
- 未部署的通用 HTTP 200 占位响应不再被当作真实社区数据或保存成功；后台同样明确报错。
- 农场只接受统一积分账本响应；旧独立币接口明确提示需要更新，不发起该接口下的交易。未转换或改动线上历史余额。
