# R30 后台会话运行时复用（本地验收）

## 结果和边界

截图中的管理后台会话入口之前每次启动都生成带随机参数的新 iframe，重新加载原生引擎、扩展和角色。这条新入口没有复用此前普通聊天的预热路径。

现在经管理员验证进入后台后，只预热通用引擎；选择角色时做只读启动数据预取。点击开始绑定已有引擎；切换后台栏目保留引擎、消息和草稿；重开/换角色需要确认并清理当前测试草稿。第一次真正就绪前保留选卡界面和按钮状态，不展示大幅品牌启动页。失败仍显示可重试提示，不假装已经连接。

删除重复构造整套对话 UI 的步骤；后台临时会话跳过不存在的历史提示词日志读写，普通会话默认持久化行为保留；迟到的授权刷新不得覆盖新角色。没有跳过扩展初始化、角色稳定检查或每轮最新预设读取，也没有用静态消息冒充可交互聊天。

**预热不足的冷启动尚未达到秒开。** 本次只解决截图对应后台工作区的重复初始化，不能宣称全应用、正式服务器和所有手机均已秒开。没有接入实机、没有重新实测 TAVO，不宣称与 TAVO 等速。

## 实测

环境：本机 Windows Chrome，使用新 APK 内的实际资源、真实本机业务后端和对话引擎。外部模型在功能回归中使用明确标识的本地合成应答；不是正式模型延迟测试。

| 场景 | 390×844 手机视口 | 1440×900 桌面视口 |
|---|---|---|
| 预热后开始/换角色，6 次 | 705–907 ms，样本 p95 907 ms | 742–977 ms，样本 p95 977 ms |
| 从其他后台栏目返回现有对话，6 次 | 82–190 ms | 76–190 ms |
| 刚进后台就点击，未等预热（1 次，外部计时） | 3669 ms | 未测 |

旧入口本机手机视口一次基线为 6920 ms。该基线不能与预热数字不加区分地对比：它包含整套引擎初始化，而预热数字不包含预热阶段。

计时：绑定从实际按钮处理函数到角色消息渲染、设置和输入就绪；栏目返回从实际选择事件到显示后的两帧；冷启动外部计时含自动化等待开销。6 个样本的 p95 只是该小样本最大值，不代表生产统计分位数。

证据：`output/mobile-r30/reuse/report.json`、同目录双视口截图、`output/mobile-r30/cold.json`、`output/mobile-r30/final-regression/`。
