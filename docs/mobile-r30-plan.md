# R30 后台会话进入延迟

## 验收目标

修复截图对应管理员会话工作区，不回退 R29 正则/权限/诊断功能。不只是隐藏启动页：复用同一个已初始化的运行时，重复进入/切角色不重建 iframe，真实消息出现且设置/输入可操作。分别记录冷启动、预热后首次绑定、再次进入和切角色耗时；目标预热后 p95 < 1 秒（样本量必须注明），未达标不能宣称秒开。

## 顺序（一次一个活动步骤）

1. [x] 测量基线：本机移动视口点击至可操作 6920 ms；原入口每次重建运行时。
2. [x] 接入管理员专用安全预热/绑定/重绑定，复用 DOM 与引擎；不自动生成、不创建普通历史。
3. [x] 工作区保留选卡界面直到真实就绪，不展示大幅启动页；异常明确提示并可重试。
4. [x] 双视口连续复用与 R29 功能回归通过；主动注入 503 后同引擎重试通过。25 项 JS、7 项 Python、43 项 Android 检查通过。
5. [x] 增量正反向校验通过；1.17.1-debug / 279 与实测说明保存于 `D:/网站/验收包/会话工作区-R30-20260927`，未提交或发布正式服。

## 未达标项（不能算整体完成）

预热后绑定与返回已小于 1 秒，但刚进后台立即开始的冷路径单次实测仍为 3669 ms。没有实机或生产部署验证，不宣称所有场景秒开。当前优化限定后台入口，普通聊天保留既有持久化和载入后重建设置行为。

## 风险

- 新后台之前使用时间戳 URL 和 x-if，完全绕过 Android 普通聊天预热。
- 预热只加载通用运行时和管理员批准的扩展，不能提前执行选中角色脚本或生成。
- 绑定必须验证父页面同源/消息来源和服务端管理员权限；不通过客户端标志授予权限。
- 未发送消息的已载入角色可以预取就绪数据，但切换不能混入上一角色的世界书、记忆、草稿或生成结果。
- 当前测试服务 8187/8188/8191 为本机隔离环境；没有连接实机，浏览器数字不能代表用户手机已达标。
