## 暗色行为规格

只读取用户提供的小黑盒 APK 已解包的公开界面资源，不复制代码/图片。观察到 night 色表包含 `general_color_bg_0_day_night=#262829`、`bg_1=#232526`、`bg_2=#1e1f21`、`bg_3=#18191b`、`bg_4=#131517`。这是资源取证，不声称每个界面均实际使用它们。

独立实现：中性石墨背景与分层灰色表面，正文亮灰、次级信息保持可读；选择窗是紧凑底部列表，选中项用勾号而不是整块蓝底/双边框。通知改为全屏任务页（Android），标题和分类固定在上方，列表/空态居中且不套巨大卡片。点击/关闭/返回保留原行为，键盘焦点和选择状态分开。浅色同步适配。不会改变角色卡 HTML 或会话自设背景。

主要风险：后端快照不是线上保证，补丁必须在实际服务器检查再部署；自消费分成、邀请规则、退款策略不能凭 UI 伪造；累计小数不能逐次丢失，重复通知/失败不能重复入账；原扣费路径和管理员授权要回归。
