## 收益接入约定（仍需后端人员提供）

复用登录后的只读 `GET /console/api/web/rewards`，扩展 `data.earnings`：

```json
{
  "summary": {
    "creator": {"amount": 12, "unit": "元"},
    "invite": {"amount": 30, "unit": "积分"}
  },
  "list": [
    {"kind": "creator", "title": "作品结算", "amount": 12, "unit": "元", "created_at": "2026-09-19", "status_label": "已入账"}
  ]
}
```

以上仅为结构示例，不是用户收入。服务端按当前登录账号鉴权；summary 只包含已入账收益，不能包含充值、赠送或账户总余额；不同单位不可相加。缺少的来源省略而不是伪造 0。本轮未提供后端分成规则、账本、邀请归因或提现实现，不宣称其已上线。
