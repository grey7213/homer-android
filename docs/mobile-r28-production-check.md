## 确认并修复的客户端缺陷

正式 `/console/api/web/dialogue/session?launch_only=1` 只返回 app_id、conversation_id，不含角色、历史、bridge_token。这是预留会话接口的正确契约，而客户端完整会话回退错误地使用了它，导致失败回退后仍缺少连接所需数据。

修复完整会话加载：移除该分支的 launch_only；嵌入端点和回退端点都验证角色及 bridge_token；不完整数据显式失败，不进入预取缓存。保留原会话 ID，不创建重复会话。启动入口真正需要预留 ID 的调用保持不变。
