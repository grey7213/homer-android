# 预设悬浮球源码移植本地交付

原组件源码已接入本地惑梦 Android 工程；不是重画的演示页。原始四组件保留在模块的 `upstream/`，适配差异在 `src/`，生成 bundle 和真实 source map 有逐文件验证。已补手机触控、安全区和明暗对比度，未改普通聊天气泡主题。

## 实现与作用域

- 原浮球拖动/点击、快速面板/展开列表、搜索、条目开关、全选和批量开启/关闭。
- 当前角色绑定的创作者预设优先，否则显示官方预设；只发送、显示明确允许公开的条目元数据。
- 单个会话内保存，其他角色/新会话保持各自默认。重新打开**同一已有会话**保留该会话的选择，不把“仅当前会话”解释成每次退出都丢失。
- 先本机持久保存，再实时/在线/回到前台时同步设置。云端旧状态不能直接覆盖本机选择；旧账号/旧会话返回不污染当前会话。
- 未确认同步时阻止生成并显示编号，不能用旧预设偷偷生成/计费。不会重放生成。
- 保存开关不刷新正则、重绘全部消息或初始化另一套 runtime。
- 原预设编辑、仓库、账号外联以及全局 fetch 改写不进入普通用户模块，正文不传给组件。

## 源码包安装顺序

本包是 R366 之后的**增量源码交付**，不是整个仓库的覆盖副本。

1. 在现有 Homer R366 工作区核对并依次保留此前补丁，直到 `20261011-integrated-r366.patch`。
2. 应用 `web-patches/20261012-preset-ball-r367.patch`；它适用于上述补丁链之后，不得当累计补丁重复叠加。
3. 原生构建流程应用 `native-build.patch`，保留 `tools/preset-ball-build/` 的代码与锁文件。`module-source/` 提供新增模块源码供查看，不用覆盖旧完整工程。
4. 后端技术人员核对 `server-patches/preset-ball-r367/manifest.json` 的基线后应用 `backend.patch`。它公开分开的 card/global 元数据、优先明确启用的角色预设，并收紧创作者公开开关白名单。**本轮没有部署**。未部署时，已有官方预设开关接口仍可用，但不能宣称正式服已具备新的角色绑定元数据。
5. 构建命令：`cd android-app && gradlew.bat testDebugUnitTest lintDebug assembleDebug -PHOMER_DEBUG_APPLICATION_SUFFIX=.presetreview`。
6. 执行 `python tools/verify_apk_assets.py` 与 `python tools/verify_preset_ball_source.py`。不要发布 debug 签名。
