## 功能

- 管理后台 → 会话工作区 → 选角色 → 开始会话。输入、发送、停止、重写、消息操作复用现有酒馆运行时。右上角侧栏直接进入模型、预设、世界书、正则、长记忆、Mod 和界面设置。
- 模型选择和采样参数作用于当前测试会话；预设和正则可选已有库、编辑/增删条目、开关，再应用到本次会话。世界书支持正文、关键词、二级匹配、触发概率、位置/深度等会话调整。
- 未调整的预设与正则每轮跟随最新模型绑定配置；应用的会话草稿保持独立。恢复默认会清除此项草稿。另有确认后保存全局预设/正则的操作，不自动改变启用项或模型绑定。世界书不写回角色原件。
- Mod 在测试会话中按当前可用版本参与世界书生成，不为此创建普通会话或写入其 Mod 配置。
- 工作区消息/草稿保留在当前页面内；刷新、换角色或重开会清空，不写入用户普通历史。长记忆扩展的账号级偏好仍沿用原有行为。
- 每条生成回复可复制诊断；内容限定编号、耗时、模型、配置指纹、正则数量等，不复制正文、密钥、请求头或世界书。长记忆等后台 quiet 生成不会误覆盖最后一条聊天回复的诊断。
- 官方正则在最终发送消息上执行，展示规则加载到原生渲染引擎；仅对已确认名称、截断表达式和空替换完全匹配的旧规则做兼容修复。其他坏规则明确失败，不静默忽略。取消不报模型错误；模型故障显示错误编号和换模型提示，积分/权限/登录错误分别提示正确操作。
