- 修复实际案例卡显示完整介绍后仍露出 HTML 源码的问题；不改作者卡内容，不隐藏普通代码，不破坏已认可的速度、账号和历史数据。
- 同一功能统一短标题“界面模板”，不再出现“界面模板（正则）”双行标题；旧 regex 路由和数据继续兼容。
- 先本地验收；用户现已要求提交分支和 PR，但不等于合并或生产部署。上一轮模拟器新导入通过不等于手机已有会话通过。

## 风险

- 原卡自带 iframe 内也可能包含被误解析的源码；外层消息没有 pre 不代表内部正确。
- 更新包不能沿用旧资源/热更新槽；测试保留登录、历史，不能清数据绕过问题。
- 不重新架构加载链路；只修改明确受影响的内容处理路径。
- 没连接实体手机时必须明确，不能由模拟器结果声称手机已通过。
