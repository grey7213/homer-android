# Tavo 1.5.0 安装包结构与独立实现规格

来源：用户提供 tavo最新新.apk，包 app.bitbear.tav，versionCode 1050。apktool 3.0.2 已解码，提取结果仅保存在忽略的 output/ui-models-r12，不进入产品或补丁。

## 已验证的结构

- Flutter 原生壳（libapp.so AOT、libflutter.so）+ 对话 WebView。原生界面不是可直接复制到本项目的 Android XML 布局。
- 可读对话实现为 assets/flutter_assets/assets/dist/index.html、css/bundle.min.css、js/bundle.min.js；字体清单为 MaterialIcons/Toastification，数学字体另置 KaTeX。
- 对话颜色由 Flutter theme 下发，CSS 默认值不等于所有主题下的实际值。保留本软件用户自定义配色；不把默认浅色硬套到已保存的深色背景。

## 模型功能规格（本软件数据链路确认）

### 原生页面结构补充（UI 自动化层级实测）

2026-09-18 本地安装 1.5.0：通过备份提醒的“以后再说”进入既有合成测试会话，再只读导航，不新建记录、不调用模型。

- 左侧聊天抽屉：顶部“全部聊天”筛选，中间历史摘要列表，底部 API 连接／角色／更多三个工具目的地。

### 小黑盒社区与个人中心规格（用户最新指定）

小黑盒.apk：com.max.xiaoheihe，1.3.379/1055。已解包到忽略目录，不复制产品代码、图片与字体。原生 XML 确認：

- fragment_community_recommend_v2：上方频道头与横向分页，内容区独立刷新/滚动，54dp 发布浮钮；不是一页堆满搜索表单。
- item_concept_feeds_link：作者区、正文区、底部互动区三个明确层次；帖子间 4dp 分隔、底部 16dp 留白。
- fragment_me_home_x：独立个人头与下方可滚动功能列表。
- fragment_me_home_v2：84dp 头像、18sp 昵称，64dp 高的等宽个人数据行；后续以当前软件实际可用数据映射，不造好友／游戏统计。
- 现有“我的”改为身份头 → 动态／收藏／消息等个人行为入口 → 资产与创作工具 → 设置；不把资料编辑长表单默认铺在首页。管理后台只给已验证管理员显示，更新入口保持最下方。

本地小黑盒目前未登录，公开信息流可以观察；未验证登录态布局的细节不会声称完全一致。

只读检查现有服务：3 个启用节点，共 26 个模型；公共目录包含 preset_id，但不包含节点名称。运行时传递状态丢失 preset_id，前后两层 select 都没有 optgroup。

- 公共模型目录补 group_id/group_name，仅公开组名与选择标识；不同节点同名模型保留，停用节点不作为回退暴露。管理密钥/URL 不下发。
- Runtime、宿主预览、缓存均保留分组，不截到 100 项；选择器显示分组、按名称/模型 ID/分组搜索，并支持分组快捷筛选。
- 管理端通过节点+模型复合键多选。提供当前搜索结果全选、全部节点全选、清空及选中数量。跨节点选择不串写同名模型。
- 批量编辑绑定预设、计价方式、输入/输出价；未勾选字段保持原值。混合值不冒充一致；改变计价单位时必须明确两项单价。应用仅改本页草稿，保存全部节点才调用现有管理员接口；取消不改，保存失败保留草稿。
- 普通用户无批量配置入口，不能读取管理员模型配置；取消选择不修改当前会话设置。

本轮没有复制第三方业务代码、品牌、图片或字体文件。原生 Flutter AOT 中未验证的布局不宣称已完整还原。网络验证只记录字段和数量，不留 Cookie/密钥或完整管理响应。

## R12 后续测量与实现（2026-09-18）

- 新建角色：同一模拟器密度 440，原生 1080×2160，状态栏 66 px。主体视口约 393×762；标题栏 44、头像 76、名字框 66、设定框 175、底部保存 47 逻辑像素。Android 实测关键矩形误差 ≤3 逻辑像素。
- 角色库：顶部返回/标题/新建；独立搜索与筛选；圆形头像约 54、横向行约 89 逻辑像素。产品中的公开状态、版本发布保留，不伪造 Tavo 的作者/版本字段。
- 选择器：浅灰底、居中标题、顶部约 32 圆角、列表行约 51；选中项灰底。额外搜索与分组只在数量需要时出现，多选保留确认区；这是适配本软件大量模型的明确差异。
- 消息菜单：独立线条 SVG，28 图标、11.3 标签、3 图文间隔、8 横向间隔；缓存页与运行时共用 500 ms 长按、10 px 移动取消与视口限制。保留较深文字及危险操作红色，未复制参照中低对比灰色。
- 新建角色全内容区像素比较（仅去状态栏，通道差阈值 20）：变化像素约 4.84%。包括自有头像、额外工具菜单、开场白非必填等刻意差异，以及尚未完全匹配的字体与细节；不将这个数字解释为全软件还原率。
- 创作工坊没有一一对应原版页面：保留本软件 4 个直接资源入口和版本业务，使用同一列表/操作层级；不声称其像素级一致。
