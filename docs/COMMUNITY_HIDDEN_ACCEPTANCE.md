# 社区入口隐藏与交互修复 · 维护者复核 2026-09-08

社区代码和服务端扩展保留，但本次提交暂不向普通用户展示社区入口。

隐藏范围：

- 移除移动端底栏、桌面侧栏和创作工坊中的社区/赛事入口。
- 直接访问社区信息流、作品库或赛事页时，普通 URL 返回探索页。
- `preview=1` 还必须通过现有管理员接口校验；普通账号不能仅靠 URL 参数打开预览。
- 不删除社区接口、帖子收藏表或页面源码，后续可恢复入口重新开放。

历史补丁保留在 PR #7 的合并提交 `3d54e8d` 中；已落地到 Web 主仓库 `b794ecc` 并纳入新 web-base，当前工作区不再重复应用该补丁。

原始补丁实际涉及 52 个网页/runtime 文件，另含聊天外观、消息隐藏/折叠/多选、通知中心、后台模型编辑和共享选项框。维护者审查后恢复误删的群聊和个人标签，修复旧账号缓存归属、深色确认框和会话外观草稿问题；消息状态保存期间阻止会话切换。

PR 没有提供新的 social 后端扩展，当前生产后端也没有该接口，因此不开放对应的后台举报入口。既有社区代码、接口和数据保留，预览不等于上线新社交服务。

原生 APK 补齐 Android 返回键对网页弹窗的取消处理，并升级到 1.15.1 (271)。应用内更新复用 1.15.0 已上线的校验下载/系统安装器机制。

维护者验证：9 项浏览器回归、桌面/390px 真实本地后端与 SillyTavern 对话操作、8 种更新入口组合、debug/release 各 32 项单测、Lint/构建/127 个前端资源核验、6 项 Android instrumentation 测试和 4 类 Android 返回键场景通过。发布及实际升级的最终记录见 `specs/pr7-release-20260908/tasks.md`。

本提交不包含 APK、签名材料或临时账号。生产部署由维护者从已验收源码出包并发布。
