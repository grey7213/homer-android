- 普通用户不可调用管理接口、访问他人私有内容或进入本机管理员验收；服务端拒绝而非只隐藏入口。
- 社区接口未部署不能显示假空列表或假成功；单独说明待服务端部署内容。
- 农场币使用账号积分账本，不通过前端改数字伪装统一；不自动兑换历史独立农场币，不触碰线上余额。
- 纯净区的搜索、推荐、缓存使用同一分区条件，不影响全库与社区原有内容规则。
- 393px 与 360px 编辑页保存/导入均可见；Android Back 先关闭面板，保留会话和滚动缓存。
- 历史摘要不执行 HTML/脚本且不显示思维链或整段网页源码。
- Debug 更新明确渠道差异，正式更新保留完整包名、签名、版本与完整性校验。
