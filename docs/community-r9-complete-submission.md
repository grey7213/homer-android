# 社区 R9 完整接入提交说明

## 问题

此前社区提交只有客户端预览，生产宿主没有 `social_*` 数据表与路由；同时强制把社区设为启动页会破坏既有对话快照恢复，删除群聊文件也会造成已发布能力回退，因此维护者在合并 PR #8 时撤下了 Web 补丁。

## 本次修复

- 增加搜索、发帖、帖子详情、评论/回复、社区动态、收藏、消息和用户主页等独立页面。
- 社区入口公开；首装走 `/app/` 部署感知入口，服务端可用时进入社区，不可用时回退探索。
- 已有 `/app/chat.html` 历史目标继续由 Android 常驻页与本地快照恢复，不强制跳社区。
- 隐藏群聊导航入口，但保留群聊页面、客户端 API 与后端能力，避免破坏存量链接。
- 增加社区管理端：举报、巡查、处罚、审核规则、公告、日志和统计。
- `server-patches/community-social/` 提供对现有后端宿主的精确接入补丁；领域服务复用仓库现有 `server-extensions/`。
- 社区角色卡引用只解析当前用户可见卡片的名称和详情 ID，不返回角色卡源文件、世界书或预设。

## 验证

- 社区领域服务：63 项隔离数据库测试通过。
- 实际宿主接入：3 项测试通过（迁移/媒体、协议/发帖/卡片解析、管理员权限）。
- Playwright：390×844、360×800、1440×900；8 个独立页面、发布编辑、搜索、个人页、评论、收藏/动态、空/删除状态全部通过；console/request failure 为 0。
- Android：`testDebugUnitTest lintDebug assembleDebug` 成功，共 50 个 Gradle task。
- APK 资源：1147 项；141 个 frontend 文件缺失 0；runtime `lib.js` 1902 KB。
- 服务端接入补丁在干净宿主文件上 `git apply --check` 和 Python 编译通过。

## 发布边界

此 PR 提交源码和接入补丁，不部署生产数据库、不提交 APK/签名/凭据。生产启用前需备份数据库、应用宿主补丁、重启服务并验证普通用户与管理员权限。
