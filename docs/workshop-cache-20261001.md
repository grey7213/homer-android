# 1.17.4（282）：工坊账号缓存隔离

工坊在 profile 尚未确认时并发请求私有作品，会把当前 Cookie 账号的数据写进旧账号缓存；原生退出登录事件还会重新排队刷新。

本次递增版本为 282，保持正式包名、签名及更新链路。增量补丁 `web-patches/20261001-workshop-account-cache.patch` 在 R25–R33 累计补丁之后应用，修复身份确认顺序、迟到请求、退出登录后的重新刷新，并清理旧工坊缓存。主 Web 真源仍为 `grey7213/AIXingYue`。

验证：

- 桌面/390px 浏览器 16/16 场景。
- Pixel 6 API 33 实际 APK WebView 8/8 场景，静态资源头确认来自 APK。
- 本地 Release 单测 43/43，debug/release 构建通过；正式包 v2/v3 签名和 zipalign 通过。
- 1,390 项包内资源、185 个 frontend 文件完整，编译前源码与编译后产物哈希校验通过。
- 在固定 Web 基线应用原累计补丁和本次补丁后，3 个文件与 Web 真源一致。

Web 文件上线不能更新旧 APK 内置资源，281 用户需要升级。设备竞态测试只使用独立 debug 包和合成 API 响应；生产用户数据不参与测试。
