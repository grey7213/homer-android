## 风险与边界

- 单独“无偿/私我”等日常词不能自动禁言；外链不等于广告，不请求用户提交的外部 URL。
- 禁言必须持久化，不能被发布请求的回滚撤销；非本人编辑失败不得用于陷害他人。
- 首次禁言时长已询问用户，待答；不默认为永久。
- 不清空现有数据库、账号或应用数据；登录信息不入报告和测试文件。
- 参考软件代码与素材不移入产品；只有可观察行为独立实现。
