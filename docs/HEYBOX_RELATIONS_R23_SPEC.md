## 本项目独立实现

整页结构：顶部返回和“关注 / 粉丝”切换，紧接名单内搜索，下面连续用户行。保留现有“我的”两个入口，不新增个人中心或假私信按钮。按钮可见框紧凑，触摸框至少 48px。

- 用户行：实际头像（失败用本应用默认头像）、单行姓名、可选简介；右侧“已关注 / 互相关注 / + 回关”。互关依据双向关系，不能凭列表类型猜。
- 搜索在服务端整个当前名单内查姓名/ID，而非只过滤已加载的 40 人。空搜索与空名单分别提示，清除搜索立即恢复列表；返回作者主页后仍保留名单类别及搜索词。
- 取消关注先确认；取消不写入。成功才变更按钮和人数；失败保持原状态。禁言时能浏览，关系操作禁用并说明。
- 小黑盒布局的实用层级映射到现有应用主题；不另换全局配色。无资料时不伪造粉丝、头像、在线状态或统计。
- 使用游标分页与请求版本号，旧请求不能覆盖新分类/搜索。用户账号切换沿用原有清理规则。

## 验收

隔离 API：跨页搜索、双向关注、人数与拉黑过滤、隐私和越权。浏览器：390×844 深浅色、1440×900，取消/回关/搜索/清除/空状态/返回，无横向溢出和控制台错误。最终 Debug 安装包在 Android 容器触摸复验；不将浏览器通过当成用户视觉认可或像素级一致。
