# R25 手机端配套接口

`mobile-r25.patch` 为客户端模型分组和正则资源页所需的服务端改动。

- 用户模型目录增加分组名称；同名模型在不同节点保留各自的分组和选择 ID。模型密钥仍不进入公开目录。
- 现有创作资源 API 增加 `regex` 类型，复用原有作者权限、私密/公开、收藏、版本与大小校验；仅存储规则，不在服务器执行正则。
- 不改变数据库结构，不迁移或删除现有作品。

维护者应在后端工作区执行 `git apply --check mobile-r25.patch`，通过后应用并重启服务。补丁未上线时，APK 无法凭空获得服务器未返回的分组名，正则的云端保存也需要这个补丁。

若维护者源码已变化，用 `tools/build_mobile_r25_server_patch.py --host <后端根目录> --stage <临时目录> --patch <补丁路径>` 对实际基线重新生成并审查，不覆盖整份后端源码。
