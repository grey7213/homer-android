# 会话服务端累计交接包

本包替代 `cumulative-r33`，包含其全部生成、计费、正则、图片功能及会话卡转换缓存。不要与旧累计服务端补丁重复叠加。缓存键包含账号、会话和完整卡内容，变更权限与可变字段仍通过新鲜请求获取。

`backend.patch` 面向既有工具目录；`manifest.json` 记录每个文件的原始与结果 LF SHA-256。先在副本中运行 `tools/verify_cumulative_server.py`，哈希匹配且没有冲突后再由维护者部署；本 PR 不自动部署服务器。

新 Python 模块与依赖文件和补丁同时交付。账号、数据库和密钥均不在此包中。
